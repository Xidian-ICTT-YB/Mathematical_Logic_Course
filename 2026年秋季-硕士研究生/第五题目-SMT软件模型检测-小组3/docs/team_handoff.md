# 资料说明

这份材料主要供后续制作实验报告、PPT 和操作演示使用，整理了实验环境、配置、数据、日志和案例原始文件。

## 做结果图表

先看 `experiment/formal-20261117-141308/`：

- `results.csv`：88 次实际运行的明细。
- `algorithm_summary.csv`：四种算法的汇总。
- `task_matrix.csv`：22 个任务在四种算法下的结果对照。
- `status_summary.csv`：全部运行状态的次数。

`runs.csv` 是计划清单，`PENDING` 只是没有回填的原始字段。做图和报告应使用实际结果表。

## 做案例和视频

`cases/` 已选 T01、T03、T05、T06、T19。每个案例可查看 CPAchecker 日志、报告和实际生成的反例或状态图。演示时建议从容易说明的 T01、T05 入手，再选一个算法结果不同的任务。其他任务的完整输出可从归档中的 `full_results.7z` 找到。

## 文件核对和最终提交

`scripts/verify_package.ps1` 可检查任务、配置和原始 XML。完整输出与 Docker 镜像建议作为附件，不必直接放入 GitHub 仓库。

提交前可再次核对文件路径、统计表、案例说明及视频中引用的结果是否一致。
